# Data

The raw OxPot data are from the supporting information of Sharma et al. 2025. Users should obtain the publisher-provided spreadsheet from the original article or publisher page and place it in `data/raw/` if they need to rerun raw-data preparation.

This repository provides the processed 15,238-row molecule-level benchmark table, five-seed split files, benchmark result tables, and plotting source data. The old 16,660-row intermediate table is not used.
