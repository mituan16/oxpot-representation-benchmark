# Data Description

## Raw data

The raw OxPot spreadsheet is not redistributed. It should be obtained from the original publication's supporting information.

## Processed data

`data/processed/oxpot_deduplicated_molecule_level.csv` contains 15,238 molecule-level entries with canonical SMILES, Eox, and scaffold labels.

## Splits

`data/splits/` contains random and Bemis-Murcko scaffold split files for seeds 11, 22, 33, 44, and 55 across eight training sizes.

## Source data tables

`tables/source_data/` contains plotting source data for the main figures.

## Excluded intermediate table

The old 16,660-row intermediate table is not used in this clean benchmark repository.
